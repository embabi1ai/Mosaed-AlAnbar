# مساعد العنبر – نسخة بسيطة

## محتويات المشروع
- `main.py`: التطبيق.
- `buildozer.spec`: إعدادات بناء أندرويد.
- `.github/workflows/android.yml`: بناء APK تلقائيًا على GitHub Actions.
- `assets/icon.png`: أيقونة التطبيق.

## البناء بأقل خطوات
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع كل محتويات هذا المجلد إلى المستودع، وليس ملف ZIP نفسه.
3. افتح تبويب **Actions** وانتظر انتهاء مهمة **Build Android APK**.
4. افتح المهمة الناجحة، ثم من **Artifacts** نزّل `mosaed-alanbar-apk`.

يمكن تشغيل البناء يدويًا من Actions عبر **Run workflow**.

## ملاحظات
- النسخة تحفظ البيانات محليًا على الهاتف.
- تذكير المياه يعمل أثناء تشغيل التطبيق فقط، وليس بعد إغلاقه بالكامل.
- لا توجد حسابات أو مزامنة أو اتصال إنترنت داخل التطبيق.
- GitHub Actions قد يحتاج وقتًا في أول بناء لتنزيل Android SDK/NDK.
- هذا إصدار أولي بسيط؛ جرّبه وتأكد من الحسابات والواجهة قبل الاعتماد عليه في إدارة العنبر.
